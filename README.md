# EMS Academy — Discord Activity

Отдельная версия EMS Academy для запуска внутри Discord. Репозитории `fourban/AnthonyEMS` и `fourban/psid-test` не изменяются.

## Сейчас
- Сохранена существующая функциональность тестов и учебных материалов.
- Добавлен отдельный мост к Discord Embedded App SDK (только handshake/ready).
- Ответы и данные кандидата не отправляются на сервер и не записываются в localStorage/sessionStorage.
- Изображения пока загружаются с публичного GitHub Pages исходного сайта, поэтому этот репозиторий не изменяет и не копирует исходные файлы.

## Публикация

В корне репозитория находится пустой файл `.nojekyll`, чтобы GitHub Pages публиковал статические HTML/CSS/JS-файлы без обработки Jekyll.
1. В GitHub открой **Settings → Pages**.
2. В **Build and deployment** выбери **Deploy from a branch**.
3. Выбери ветку `main` и папку `/ (root)`, сохрани.
4. После публикации укажи выданный URL в Discord Developer Portal → Activities → URL Mappings.
5. Корневая привязка должна вести к опубликованному сайту. Проверь активность внутри Discord после обновления.

Это статический сайт; сервер или база данных не нужны. SDK подключается из публичного CDN.
